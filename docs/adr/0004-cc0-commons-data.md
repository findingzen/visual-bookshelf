# 0004 — CC0 for shared catalog data

**Status:** Accepted · **Date:** 2026-10-13

## Context

The Commons is a shared catalog of bibliographic facts contributed by users: titles, ISBNs, dimensions, cover and spine images. Its main upstream source, Open Library, publishes its metadata as CC0.

## Decision

Bibliographic data contributed to the Commons is released under **CC0** (public domain dedication). Personal data — ownership, location, notes, ratings — never enters the Commons.

## Consequences

- Data can flow both ways with Open Library without license conflicts.
- Contributors must be told clearly, at the point of contribution, that their bibliographic contributions are public domain.
- Cover images may carry the publisher's copyright regardless of our license; how cover images are shared needs its own review before a hosted Commons exists.
